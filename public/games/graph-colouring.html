🎨 Graph Colouring Challenge

How to Play

Select a colour from the palette, then click a vertex to colour it. Your goal: colour every vertex so that no two adjacent vertices share the same colour, using as few colours as possible. The minimum number needed is called the chromatic number χ(G).

Theory Notes

A colouring assigns colours to vertices so no adjacent vertices share a colour. The chromatic number χ(G) is the minimum number of colours needed. If a graph contains Kn as a subgraph, then χ(G) ≥ n.
