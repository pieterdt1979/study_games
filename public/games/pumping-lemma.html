Pumping Lemma (with length)

If L is context-free, then for any word w with |w| > 2ᵖ, w can be decomposed as uvxyz where:

1. |vxy| ≤ 2ᵖ
2. |x| > 0
3. |v| + |y| > 0

and uvnxynz ∈ L for all n ≥ 0.

To prove L is NOT CF: find a word where EVERY valid decomposition produces a pumped word NOT in L.
