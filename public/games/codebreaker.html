How to Play

A secret code of coloured pegs has been generated. Select a colour from the picker, then click peg positions to place your guess. After each guess, you'll receive feedback: ⚪ White = correct colour, wrong position. ⬛ Black (white dot) = correct colour AND position. Use logic to crack the code!

Counting Connections

With 4 positions and 6 colours (repetition allowed), there are 6⁴ = 1296 possible codes. This is an arrangement with repetition — like placing objects in ordered positions where each position has independent choices (multiplication principle).

Strategy Tip

Start with a guess using all different colours to maximise information. Each response eliminates many possibilities.
