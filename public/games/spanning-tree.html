How to Play

Click on edges to add them to your spanning tree. Build a tree that connects ALL vertices with minimum total weight. A spanning tree has exactly n-1 edges (where n = number of vertices) and no circuits. Use Kruskal's strategy: always pick the cheapest available edge that doesn't create a circuit!

Algorithm Notes

Kruskal's algorithm: Sort edges by weight. Pick the cheapest edge that doesn't form a circuit. Repeat until you have n-1 edges.

Prim's algorithm: Start from any vertex. Always add the cheapest edge connecting a tree vertex to a non-tree vertex.
