How to Play

Block Walking: C(n,r) = number of paths from (0,0) to (r, n-r) using only right (→) and up (↑) steps. Click grid cells to trace a path. Pascal's Triangle: Select entries that sum to prove an identity. Evaluate: Compute values using the binomial theorem.

Block Walking Model

C(n,r) = paths from (0,0) to (r,n-r) on a grid, moving only → or ↑.

Pascal's identity: C(n,r) = C(n-1,r-1) + C(n-1,r)
Proof: paths to (r,n-r) must come from (r-1,n-r) [→ step] or (r,n-r-1) [↑ step].

Binomial theorem: (1+x)ⁿ = Σ C(n,k)xᵏ
