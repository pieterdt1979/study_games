How to Play

Given a language description, write the regular expression that generates exactly that language. Use: a, b (letters), + (union), * (Kleene star), concatenation, and Λ (empty word). Alphabet is {a, b}.

Regex Syntax

a — matches 'a'
ab — concatenation (a then b)
a+b — union (a or b)
a* — zero or more a's
(ab)* — zero or more 'ab's
Λ or λ — empty word

Precedence: * > concatenation > +

Key insight: Regular expressions generate exactly the regular languages — the same languages accepted by FAs/NFAs.
